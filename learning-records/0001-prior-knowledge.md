# 先前水平：Rust 入门已完成，axum 学到中间件，零 Rails

Rust 新手阶段已学完。axum 正在学，自述已学过：参数提取（extractor）、返回值（IntoResponse）、测试、带状态的路由（State）、中间件。从没用过 Rails。所以第一课可以直接用 axum 概念做锚点（Loco 的路由和中间件就是 axum），Rails 惯例（约定优于配置、生成器、migration）要从零解释。

Evidence: 学习者在首次对话中自述（2026-10-24）。深度未经练习验证，axum 部分按“学过、未必熟练”处理。

Implications: 讲 Loco 时用 axum → Loco 对照；DDD 分层是目标之一，但先把框架默认结构跑通再谈拆层。
